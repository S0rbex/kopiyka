# platform-starter

Спільний Spring Boot starter для всіх Java-сервісів. Тут лежить те, що інакше копіювалося б у кожен сервіс.

## Що з'явиться у фазі 0

- помилки у форматі Problem Details (RFC 9457) і заголовок `Request-Id`
- Jackson: `snake_case` і строгий парсинг (невідоме поле → помилка)
- бін `Clock`, щоб у тестах керувати часом
- базовий клас для інтеграційних тестів з Testcontainers

Пізніше: ідемпотентність, outbox, inbox.

**Правило:** сюди потрапляє тільки технічна «обв'язка». Бізнес-логіка (платежі, баланси) — ніколи.
